Maple Ledger — a household budget site for the Maple household (Maya, Daniel, and Lily, age 8). Dashboard, transactions, budgets, savings goals, bills, and reports, all working from one set of real figures: November income $7,070.00, spending $3,943.18, saved $900.00. Add transactions, edit budgets, fund goals, and mark bills paid — everything persists in localStorage. Static files only: no build step, no network requests, works on desktop and phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
